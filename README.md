# JuicyBites Website Project

## Project Overview
Multifaceted responsive web application built for a food business named JuicyBites, showcasing its menu, about details, and an interactive customer enquiry form.

## Technologies Used
- Visual Studio Code
- HTML5 & CSS3
- Git & GitHub (Repository: `banaminentle-netizen`)

---

## Changelog

### Part 2 Updates & Part 1 Feedback Fixes (2026-09-17)
- **Feedback Corrections:** Fixed unclosed HTML tags, restored active semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), and added structural comments across `index.html` and `about.html`.
- **External Stylesheet Integration:** Created and linked `style.css` to all HTML pages for consistent layout, typography, and color schemes.
- **Interactive Pseudo-Classes:** Added `:hover` and `:active` styles for navigation links and form buttons.
- **Responsive Design:** Implemented relative sizing units (`rem`, `%`) and media query breakpoints (`max-width: 768px`) for optimal mobile layout switching.
